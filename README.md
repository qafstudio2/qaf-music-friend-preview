# QAF 吉他學習實驗工坊｜朋友測試版

公開版由 `index.html` 與 `qaf-page-*.html` 組成，包含首頁、各標籤頁的實際圖片，以及每日記憶的五度圈、音階和圖表互動。載入時顯示極簡進度條與百分比。

測試版與原站分開；沒有連接本機網站、NAS、PDF、私人影音、閱讀紀錄或儲存功能。我的音樂顯示頁面圖片；進度總覽顯示 2026-09-30 的完整靜態快照，數字不會自動更新。公開外部來源連結保留；私人 Google Drive 與 IG 收藏網址已移除。

頁首的「瀏覽次數」由 hits.sh 的公開圖片計數器提供，只有在 GitHub Pages 網址開啟時載入；本機預覽不計入。這是自加入計數器後的頁面開啟次數，不是獨立訪客數，也不含先前流量。切換站內標籤不會再加一次。

公開網址：https://qafstudio2.github.io/qaf-music-friend-preview/
